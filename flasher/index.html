ESP32-RF-SWORD

Official 1-Click In-Browser Firmware Installer for ESP32, ESP32-C3 SuperMini, and ESP32-S3 devices.

  1. Connect your ESP32 board to your computer via USB.
  2. Ensure you are using Chrome, Edge, or an Chromium-based browser.
  3. Click CONNECT below and select the Serial/COM port.
  4. Select Install ESP32-RF-SWORD and confirm.
Web Serial API not supported by this browser. Please use Google Chrome or Microsoft Edge.
