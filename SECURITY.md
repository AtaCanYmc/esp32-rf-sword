# Security Policy & Ethical Use Guidelines

## 1. Intended Use & Ethical Disclaimer

**ESP32-RF-SWORD** is an advanced open-source experimental research framework designed exclusively for:
- Academic study and RF hardware security analysis.
- Controlled RF testing inside RF anechoic chambers, Faraday cages, or shielded test fixtures.
- Authorized penetration testing and defense auditing of IoT and wireless devices.
- Educational exploration of SPI bus multiplexing, spread spectrum physics, and FreeRTOS embedded systems.

> [!CAUTION]
> **Legal Notice**: Transmitting radio frequency signals on unauthorized spectrum or disrupting licensed communications (cellular, aviation, emergency services, Wi-Fi infrastructure, etc.) without explicit authorization is illegal in most jurisdictions under national communications laws (e.g. FCC regulations in the United States, ETSI/RED directives in the European Union).
> The authors and maintainers accept **no liability** for misuse or damages resulting from this software.

---

## 2. Responsible Vulnerability Disclosure

If you discover a security vulnerability in ESP32-RF-SWORD (such as an exploit in the WebServer, Wi-Fi portal, or NVS memory handling), please report it responsibly:
1. Do not file public GitHub issues for security vulnerabilities.
2. Submit details via private security advisory or contact the core maintainers.
3. Allow up to 30 days for remediation before public disclosure.
